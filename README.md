# مشروع حجز صالة المدرسة

واجهة عربية RTL بألوان أخضر غامق وذهبي، تتضمن:
- نموذج حجز مع تاريخ ووقت بداية ونهاية.
- منع تعارض الأوقات في النسخة التجريبية.
- تقويم/قائمة عامة لا تعرض اسم صاحبة الحجز.
- تصدير CSV.
- تصميم متجاوب للآيفون والكمبيوتر.

## مهم قبل الاستخدام الفعلي
هذه نسخة أولية تعمل محليًا فقط، وتخزن الحجوزات في متصفح الجهاز باستخدام `localStorage`. هذا يعني أن الحجوزات لا تنتقل بين الأجهزة ولا تصلح للنشر الرسمي قبل ربط قاعدة بيانات مشتركة وتأمين لوحة الإدارة.

## تشغيل تجريبي على ويندوز
1. فك ضغط الملف.
2. افتحي مجلد المشروع.
3. انقري مرتين على `index.html` لفتحه في المتصفح.

## نشر الموقع برابط عام
تحتاجين:
1. رفع الملفات إلى GitHub.
2. إنشاء مشروع Supabase وربط قاعدة البيانات مع التطبيق.
3. نشر الواجهة عبر Vercel.
4. إضافة تسجيل دخول للمديرة وسياسات أمان مناسبة قبل مشاركة الرابط.

ملف `supabase_schema.sql` مجرد بداية لمخطط قاعدة البيانات وليس تكاملًا جاهزًا.
